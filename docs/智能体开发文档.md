## 一、智能体是什么

大模型本身只会"生成文字"。智能体 = 大模型 + 工具调用 + 记忆 + 循环执行。
本项目实现的是一个**项目秘书**：它通过 Function Calling（函数调用）把自然语言转化为
真实的系统操作——查询项目、创建任务、提交周报、生成提醒——执行权始终在
后端受控工具中，带权限校验，不绕过系统权限模型。

```
用户（Web 对话 / 需求拆解） → 智能体路由（routes/assistant.py）
        → LLM 大脑（services/ai_service.py，OpenAI 兼容）
        → 工具层（services/assistant_tools.py，带权限校验）
        → 业务数据（projects/tasks/milestones/weekly_reports/reminders/notifications）
```

## 二、已实现功能

### 1. 智能对话（Function Calling 工具循环 + SSE 流式输出）

- `POST /api/assistant/chat`：接收用户消息，循环执行 工具调用 → 工具结果 → 再思考，
  最多 5 轮，最终返回回答与工具调用记录。
- `POST /api/assistant/chat/stream`：**SSE 流式对话**（前端打字机效果），事件序列：
  `ready`（已连接）→ `delta`（回答增量，逐字显示）→ `tool_start`/`tool_done`
  （工具执行实时状态）→ `done`（完整回答 + 工具记录）；出错时返回 `error` 事件。
- **对话持久化与会话隔离**：每次对话自动创建会话（标题取首条消息），
  用户消息/助手回复/工具记录写入数据库；可新建/切换/重命名/删除会话，
  切换对话自动加载对应历史记录，会话严格按成员隔离。
- **调用防护**：每成员每分钟限流（默认 30 次）、单条消息长度上限（默认 4000 字）、
  工具结果自动裁剪（防止上下文膨胀）；历史消息也按长度截断。
- 工具注册表共 26 个工具，覆盖：
  项目（查询/详情/里程碑）、任务（查询/创建/状态更新）、成员目录、平台统计、
  周报（创建/提交/AI 分析）、提醒（创建/完成/列表）、通知、资源中心搜索、
  获奖记录、博客公告、个人证书、项目健康度（完成率/逾期/负载）、AI 周报草稿。
- 权限规则：任务状态更新仅限任务负责人或项目负责人；周报/提醒只能操作自己的；
  写操作前模型需向用户确认关键信息。

### 2. 需求拆解 → 方案确认 → 落地创建（旗舰能力）

- `POST /api/assistant/parse-requirement`：把模糊的自然语言需求解析为结构化方案
  （项目信息 + 2~5 个里程碑 + 最多 20 个任务，含负责人/优先级/截止日期）。
- 方案仅返回给用户预览，**不写库**。
- `POST /api/assistant/apply-plan`：用户确认后一次性创建
  项目 + 里程碑 + 任务，并按任务分配自动给负责人发送站内通知。

### 3. 周报系统

- 数据表 `weekly_reports`：content(JSON) / ai_analysis(JSON) / completion_rate /
  status(draft/submitted/reviewed) / review_note。
- 成员端：创建草稿、编辑、提交、AI 分析（`POST /api/member/weekly-reports/<id>/analyze`）。
- 管理端：查看全部周报、审阅（写批注 + 完成度，自动通知提交者）、AI 分析。

### 4. 提醒系统

- 数据表 `reminders`：type(task_due/report_submit/review/custom) / scheduled_at / status。
- 成员端：创建/修改/完成自己的提醒。
- 管理端：教师可给任意成员创建提醒。
- 定时扫描服务 `services/reminder_service.py`：后台守护线程（默认 3600s 一次）：
  到期提醒 → 生成站内通知；24 小时内到期的任务 → 自动提醒负责人（24h 内不重复）。
  周报提交催收 → 有未完成任务且本周未提交周报的成员自动提醒（7 天内不重复）。
- 外部通知通道 `services/notification_channels.py`：可选飞书 Webhook / SMTP 邮件。
  站内通知始终写入数据库，外部通道失败只记录日志，不阻塞周报或提醒主流程。

## 五、配置说明

在 `.env` 或环境变量中配置（与 OCR 共用 OpenAI 兼容模式）：

```bash
AI_ENABLED=true
AI_PROVIDER=deepseek   # 或 qwen / zhipu / kimi / openai 等
AI_API_KEY=你的密钥
AI_BASE_URL=https://api.deepseek.com/v1   # 任意 OpenAI 兼容端点
AI_MODEL=deepseek-chat

REMINDER_SCAN_ENABLED=true
REMINDER_SCAN_INTERVAL=3600
REMINDER_SCHEDULER_BACKEND=thread     # thread / apscheduler / disabled
REMINDER_SCHEDULER_TIMEZONE=UTC
REMINDER_SCHEDULER_LEADER=true        # 多实例部署时仅 leader 实例开启
ASSISTANT_CHAT_MAX_TOKENS=2048   # 对话单次回答最大输出 token
ASSISTANT_PARSE_MAX_TOKENS=4000  # 需求拆解单次生成最大输出 token

NOTIFICATION_FEISHU_ENABLED=false
FEISHU_WEBHOOK_URL_FILE=/run/secrets/feishu_webhook_url

NOTIFICATION_EMAIL_ENABLED=false
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_FROM=noreply@example.com
SMTP_USERNAME_FILE=/run/secrets/smtp_username
SMTP_PASSWORD_FILE=/run/secrets/smtp_password
SMTP_USE_TLS=true
SMTP_USE_SSL=false
```

任选国内兼容厂商即可：DeepSeek、通义千问（DashScope 兼容模式）、智谱 GLM、
Kimi（Moonshot）都支持 OpenAI chat completions 协议，无需改代码。

## 六、前端使用

成员登录后，侧栏「智能 → AI 助手」进入 `/member/assistant`：

1. **智能对话**：自然语言问答（打字机流式输出），可查询项目/任务/成员、
   创建任务/提醒、提交和分析周报，工具执行过程实时显示状态标签。
   左侧对话列表支持新建/切换/重命名/删除，切换后自动加载历史记录；
   助手回复支持 Markdown 渲染（列表/代码/加粗等）与一键复制。
2. **需求拆解**：输入模糊需求 → AI 生成方案 → 确认后一键创建项目+里程碑+任务。
   AI 生成过程**实时流式显示**（边生成边滚动），完成后自动整理成方案卡片。
3. **我的周报**：创建/提交周报，一键 AI 分析（完成度评分 + 风险 + 审核报告）。
