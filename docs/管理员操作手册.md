# 管理员操作手册

> 适用对象：实验室负责人、教师、平台管理员
> 更新日期：2026-08-09

## 一、登录

1. 访问网站，点击导航栏「登录」。
2. 输入管理员用户名与密码（开发环境默认 `admin / admin123`，生产环境由部署者设置）。
3. 登录后进入 `/admin` 管理后台。

## 二、仪表盘

展示成员、项目、奖项、博客、入社申请、留言的统计数据与快捷入口，
待处理申请/留言可一键跳转。

## 三、内容管理

### 3.1 成员管理（/admin/members）

- 新建/编辑成员：姓名、角色、分组、年级、技能、联系方式、状态。
- 删除成员（谨慎操作）。

### 3.2 证书审核（/admin/certificates）

1. 状态筛选：待审核 / 已认证 / 已驳回。
2. 查看证书图片、AI 识别字段与识别原文。
3. 点击「通过并归档」：证书转已认证，自动生成一条成果（Award）到实验室成果库，并通知成员。
4. 点击「驳回」：填写原因，成员收到通知后可修改后重新送审。

### 3.3 项目管理（/admin/projects）

列表页支持搜索、分类筛选、新建/编辑/删除。
点击行内「详情」进入 `/admin/projects/<id>`，含 6 个 Tab：

- **概览**：编辑项目名称、状态、分类、起止日期、GitHub/演示地址、描述。
- **任务看板**：5 列状态（待办/进行中/待审核/已完成/已阻塞），卡片左右移动流转，
  新建/编辑任务（负责人、里程碑、优先级、截止日期）。
- **里程碑**：创建阶段节点，进度条展示任务完成情况。
- **周报**：查看该项目成员周报，跳转周报审阅页。
- **提醒**：为成员创建任务截止/周报提交/审阅/自定义提醒。
- **统计**：完成率、任务状态分布、逾期任务、成员负载、里程碑进度、最近截止。

### 3.4 周报审阅（/admin/weekly-reports）

1. 筛选：待审阅 / 已审阅 / 草稿。
2. 打开详情：查看本周完成、下周计划、问题风险、总结。
3. 点击「AI 分析」生成完成度评分、风险与建议（需配置 AI）。
4. 填写批注与人工完成度（0-100），点击「标记已审阅」；已审阅可更新。

### 3.5 奖项管理（/admin/awards）

奖项 CRUD；证书审核通过后自动生成的成果（`certificateId` 来源）也会显示在这里。

### 3.6 博客管理（/admin/blogs）

- 写文章：标题、摘要、Markdown 正文、分类（含「公告通知」）、标签、作者、封面。
- 「置顶」开关：置顶文章在官网博客列表与首页公告区优先展示。
- 发布/草稿状态切换、删除。

### 3.7 页面管理（/admin/pages）

维护 CMS 页面内容（JSON 结构）：研究方向、合作交流、招新信息、新手指南。
保存后官网对应页面即时生效。

- 「关于我们」页的正文与统计数字在「站点配置 → Hero / 关于我们」中维护。
- 「雨记」目前是固定演示页，暂未接入页面管理。

## 四、运营

### 4.1 站点配置（/admin/config）

- Hero 区域：眉题、主标题、描述、背景视频 URL、两个按钮的文字与链接。
- 关于我们：标题、两段描述（首页「关于」与 `/about` 页共用）。
- 成员 / 作品 / 奖项 / 加入区域：各区块的英文标签、标题、底部按钮与 CTA 文案。
- 时间线：页面标题、简介与大事记条目（可增删、上下移动）。
- 页脚：品牌名、标语、Logo、介绍、GitHub 链接、联系邮箱。
- **联系我们**：地址、邮箱、电话、开放时间（官网 `/contact` 页同步显示）。
- 区块开关：控制首页 Hero / 关于 / 成员 / 作品 / 奖项 / 公告 / 加入 CTA 的显隐。
- 标题支持两种轻量标记：`**文字**` 渲染为衬线强调，换行符直接换行；描述中的空行分段。

> 说明：成员、作品、奖项、博客的**条目内容**在各自的管理页维护；站点配置只负责页面文案与区块开关。

### 4.2 入社申请（/admin/applications）

查看报名列表，审核（通过/驳回）并填写备注。

### 4.3 留言管理（/admin/contacts）

查看访客留言，标记已读、回复留言（状态自动变为「已回复」）、内部备注。

### 4.4 数据管理（/admin/data）

- 导出：全站配置、页面、成员、项目、奖项、博客为 JSON。
- 导入：支持 replace（清空重建）与 merge（合并）两种模式，用于备份恢复与环境迁移。

## 五、AI/OCR 配置提示

证书智能识别与周报 AI 分析依赖视觉/文本大模型：

```bash
AI_ENABLED=true
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=<密钥>
AI_MODEL=deepseek-chat

OCR_ENABLED=true        # 证书识别（视觉模型）
OCR_ENDPOINT=...
OCR_API_KEY=...
OCR_MODEL=deepseek-vl
```

未配置时对应功能返回「未配置」提示，其余功能不受影响。

## 六、常用排查

| 现象 | 处理 |
|------|------|
| 证书识别提示未配置 | 检查 `OCR_ENABLED/OCR_ENDPOINT/OCR_API_KEY/OCR_MODEL` |
| AI 分析提示未配置 | 检查 `AI_ENABLED/AI_BASE_URL/AI_API_KEY/AI_MODEL` |
| 上传失败 | 检查 `UPLOAD_FOLDER` 磁盘空间与权限；OSS 模式检查密钥 |
| 忘记管理员密码 | 生产环境删除数据库后由 `BOOTSTRAP_ADMIN_PASSWORD` 重建，或联系开发重置 |
