# 师生使用手册

> 适用对象：实验室教师、在读学生
> 更新日期：2026-08-09

## 一、账号与登录

1. 管理员在「成员管理」中预置成员信息（姓名、学号、邮箱等）。
2. 首次登录：点击导航栏「登录」→「注册」：填写学号/邮箱 + 姓名 + 密码（≥6 位），
   姓名与预置信息匹配后自动激活。
3. 之后可用学号/邮箱 + 密码登录；也可在个人资料中修改密码。

开发环境演示账号：`2022001 / member123`（陈星宇）等。

## 二、个人中心（/member/*）

登录后进入成员门户，左侧导航：

| 模块 | 功能 |
|------|------|
| 工作台 | 统计概览、快捷入口 |
| 我的项目 | 项目列表，点击进入项目看板 |
| 项目看板 | 任务 5 列状态流转，创建/编辑任务 |
| 我的任务 | 个人任务列表（优先级/截止排序） |
| 资源中心 | 文件夹树、上传/下载、搜索 |
| 证书管理 | 上传证书、AI 识别、查看审核状态 |
| 通讯录 | 团队成员联系方式 |
| 通知中心 | 任务/周报/公告通知 |
| 个人资料 | 编辑资料、修改密码 |
| AI 助手 | 智能对话、需求拆解、我的周报 |

## 三、证书智能识别（重点功能）

1. 进入「证书管理」→「添加证书」。
2. 上传证书图片（PNG/JPG/WebP，≤10MB，最多 5 张）。
3. 点击「AI 识别并自动填充」：自动识别获奖名称、等级、颁奖单位、**指导教师**、
   获奖时间、获奖人、类别等字段并回填表单（识别原文可展开核对）。
   证书上没有指导教师时该字段留空。
4. 人工修正任何字段后保存提交，状态为「待审核」。
5. 管理员审核通过后：状态变「已认证」，成果自动归档至实验室成果库，你会收到站内通知；
   被驳回时按原因修改后保存会自动重新送审。

## 四、周报

- 入口：「AI 助手」→「我的周报」，或直接问 AI「创建我的周报」。
- 填写本周完成、下周计划、问题风险、总结；可先存草稿再提交。
- 提交后进入教师审阅流程；可一键「AI 分析」查看完成度评分与建议。
- 教师在管理后台 `/admin/weekly-reports` 审阅，批注会以通知形式反馈给你。

## 五、智能项目管理智能体

### 5.1 智能对话

自然语言提问即可操作：

```text
查看我的任务
帮我把任务 42 状态改为进行中
创建一条周五交周报的提醒
搜索资源中心的「设计规范」
```

工具执行过程实时显示，写操作前会向你确认关键信息。

### 5.2 需求拆解

输入模糊需求（如「做一个 AI 学习助手，10 月前上线」）：

1. AI 生成项目 + 里程碑 + 任务方案（流式预览，不写库）。
2. 人工确认方案（可调整）。
3. 点击「创建」，一次性落地项目/里程碑/任务，负责人自动收到通知。

## 六、资源中心

- 登录后可见；支持文件夹树、面包屑、标签/关键词搜索。
- 可上传文档、代码、图片、压缩包等；删除为软删除（回收站可恢复，由管理员处理）。

## 七、通知与提醒

- 顶部铃铛实时显示未读数量（NotificationWatcher 轮询）。
- 通知中心按类型查看：任务分配、状态变更、里程碑、公告。
- 提醒可由自己或教师创建（任务截止/周报提交/审阅/自定义），到点自动生成站内通知。

## 八、公告已读

官网「博客/公告」列表显示置顶公告；登录成员打开公告详情后自动标记已读，
列表中出现「已读」标识。

## 九、CLI 使用（可选，面向自动化/大模型）

```bash
python -m cli auth login
python -m cli report submit --done "本周完成..." --plan "下周计划" --issues "无"
python -m cli task list --mine
python -m cli award export --format csv --output awards.csv
```

详细命令参考见《CLI接口调用文档》。

## 十、常见问题

| 问题 | 处理 |
|------|------|
| 注册提示「未找到匹配的成员信息」 | 请联系管理员先在成员管理中录入你的信息 |
| 证书识别无结果 | 检查图片清晰度；确认管理员已配置 OCR 模型；可手动填写 |
| 周报提交后想修改 | 已提交不可修改，可联系教师在管理端处理，或下次周报补充 |
| 忘记密码 | 联系管理员重置（管理员暂无自助重置，可删除成员后重建或修改数据库） |
