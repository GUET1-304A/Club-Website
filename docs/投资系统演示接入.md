# 投资管理系统演示接入

官网 `/projects` 增加独立投资管理系统模块。按钮请求
`GET /api/demos/investment/launch`，固定跳转至 `/projects/investment/`，
再进入 `https://investment.304aistudio.cn/`。接口不接受调用方提供的跳转地址。

投资系统继续运行在台式机 `127.0.0.1:9012`。独立域名保留它现有的根路径、
静态资源、API、登录及业务页面，不与官网 `/api` 混用，不自动登录或迁移业务数据。

## 一次性接入

1. 为 `investment.304aistudio.cn` 配置 A 记录 `39.101.66.98`。
2. 本机创建专用 Ed25519 密钥，私钥和核验过的服务器 `known_hosts` 存在忽略目录
   `.local/relay/`，不上传私钥。
3. 上传公钥，执行 `scripts/setup-investment-relay.sh 公钥文件`。
   专用 `investment-relay` 用户只允许远程 Unix socket 转发，禁止交互终端、
   密码认证、TCP 转发及代理转发；不会获得 sudo 或官网数据权限。
   为兼容服务器 OpenSSH 8，配置用 `AllowTcpForwarding remote` 配合
   `PermitListen none`：开启 Unix socket 所依赖的远程转发门禁，同时拒绝全部 TCP 监听目标。
4. 按 `scripts/start-investment-relay.ps1` 建立到服务器现有 SSH 端口的加密通道。
   服务器 socket 为 `/srv/304aistudio/investment-relay/relay.sock`，不开放新的公网应用端口。
5. DNS 生效后执行 `scripts/extend-investment-certificate.sh`，使用原 ACME 账号和
   私钥将演示域名加入现有证书。该步骤按现有续期方式短暂停止官网前端，退出时恢复。
   原证书续期任务继续使用同一证书名称和文件路径。
6. 按生产更新手册完成正式提交、完整预检、对应 CI、备份恢复演练和发布。
   TLS Compose 仅给前端增加 socket 目录挂载，原业务卷保持原样。

## 运行与验证

- 台式机保持开机，投资系统及 `start-investment-relay.ps1` 保持运行。
  脚本断线后自动重连，使用互斥锁防止本机重复启动，可注册为当前用户登录启动任务。
- 公网访问必须经过 HTTPS，保留投资系统原账号登录，代理为会话 Cookie 增加 Secure。
  演示域名不进入搜索索引，接口文档不对公网开放。
- 验证官网卡片、两次固定跳转、演示登录页面、入口资源及未登录接口权限。
  需要账号的业务验证使用已有授权账号，不创建或改写投资业务记录。
- 隧道断开时返回 HTTP 503 与可重试的离线页面；官网其他页面及其他服务器项目不依赖此通道。
- 停用时停止本机启动任务和隧道；需要撤销接入时移除专用用户公钥及对应 SSH Match 配置。
  网站回退仍按生产更新手册处理，不删除数据卷、历史镜像、发布目录或备份。
