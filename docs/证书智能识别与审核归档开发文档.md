# 证书智能识别与审核归档 — 开发文档

> 对应任务书：任务 4（个人中心 + 证书智能识别录入模块，重点功能）

## 一、功能闭环

```
成员上传证书图片（PNG/JPG/WebP）
        │
        ▼
AI 结构化识别（获奖名称/等级/类别/获奖人/颁奖单位/获奖时间/描述 + 原文转录）
        │
        ▼
表单自动回填 → 成员人工修正 → 提交（status = pending）
        │
        ▼
管理端审核（/admin/certificates）
        ├── 通过 → 自动生成 Award（实验室总成果库）+ 站内通知
        └── 驳回 → 站内通知；成员修改后自动重新送审（rejected → pending）
```

## 二、后端实现

### 2.1 OCR 服务（`backend/services/ocr_service.py`）

- `extract_text(images)`：纯原文转录（兼容保留）。
- `extract_fields(images)`：返回 `{"ocr_text": str, "fields": {...}}`。
  - 字段：`name`、`level`（national/provincial/school/other）、`category`、`winner`、
    `issuer`、`date`、`description`；
  - 自动容错：Markdown 代码围栏、非 JSON 输出降级为空字段、等级文案归一化；
  - 只返回供应商提供的内容，绝不生成占位识别结果。

### 2.2 成员端 API（`backend/routes/member.py`）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/member/certificates/upload` | 上传证书图片（jpg/png/webp，10MB） |
| POST | `/api/member/certificates/ocr` | 对已上传图片直接识别，返回 `ocrText` + `ocrFields`（供表单回填） |
| POST | `/api/member/certificates/<id>/ocr` | 对已保存证书重新识别，持久化 `ocr_text`/`ocr_fields` |
| PUT | `/api/member/certificates/<id>` | 人工修正；被驳回后保存自动重新送审 |

### 2.3 管理端 API（`backend/routes/admin.py`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/certificates` | 证书列表（status/memberId/search 筛选） |
| GET | `/api/admin/certificates/<id>` | 证书详情 |
| POST | `/api/admin/certificates/<id>/review` | `{"status": "verified"|"rejected", "reviewNote"}`；通过时自动归档 Award（幂等）并通知成员 |

### 2.4 数据模型

- `certificates` 表新增：`ocr_fields`（JSON）、`review_note`、`reviewed_by`、`reviewed_at`。
- `awards` 表新增：`certificate_id`（来源证书，唯一归档关联）。
- 迁移由 `backend/app.py` 的 `_migrate_columns()` 自动执行（SQLite 兼容，幂等）。

## 三、前端实现

### 3.1 成员端（`frontendnew/src/components/member/CertificateManager.tsx`）

- 表单内「AI 识别并自动填充」按钮：调用 `/api/member/certificates/ocr`，识别成功自动回填
  名称/等级/类别/获奖人/机构/日期/描述，并在表单下方展示识别原文；
- 卡片上显示「AI 已识别 N 项字段」；识别原文可展开查看。

### 3.2 管理端（`frontendnew/src/components/admin/AdminCertificates.tsx`）

- 路由 `/admin/certificates`，侧边栏「内容管理 → 证书审核」；
- 待审核/已认证/已驳回/全部筛选 + 关键词搜索；
- 卡片展示图片、提交人、识别字段标签、识别原文、审核批注；
- 「通过并归档」「驳回」操作，可填写批注/原因；
- 详情弹窗展示完整字段与识别原文。

## 四、配置

```bash
OCR_ENABLED=true
OCR_ENDPOINT=https://api.deepseek.com/v1   # 任意 OpenAI 兼容视觉端点
OCR_API_KEY=你的密钥
OCR_MODEL=deepseek-vl                        # 或 qwen-vl / gpt-4o 等
```

未单独配置时可回退使用 `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL`。详见
`docs/integrations.md` 与 `.env.example`。
