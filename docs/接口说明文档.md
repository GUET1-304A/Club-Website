# 接口说明文档

> 项目：实验室综合官网及智能项目管理平台
> 更新日期：2026-08-09
> 全文约 130 个 REST 端点，统一前缀 `/api`，请求/响应均为 JSON（上传接口为 multipart/form-data）。

## 一、通用约定

- Base URL：`http://<host>:5000/api`（生产环境经 Nginx 转发）。
- 认证：`Authorization: Bearer <token>`；管理员 token 与成员 token 体系互斥。
- 错误格式：`{"error": "error_code", "message": "人类可读消息"}`。
- 列表筛选：Query 参数（`status`、`category`、`search`、`level`、`memberId`、`projectId` 等）。
- 时间格式：ISO 8601（如 `2026-08-09T10:00:00+08:00`），日期字段支持 `YYYY-MM-DD`。
- 健康检查：`GET /health`（无 `/api` 前缀）返回 `{"status":"ok"}`。

## 六、关键接口示例

### 6.1 统一登录

```http
POST /api/auth/login
Content-Type: application/json

{"account": "2023001", "password": "member123"}
```

```json
{
  "success": true,
  "token": "<jwt>",
  "role": "member",
  "user": {"id": 3, "name": "赵子涵", "studentId": "2023001"}
}
```

### 6.2 证书智能识别（表单回填）

```http
POST /api/member/certificates/ocr
Authorization: Bearer <member-token>
Content-Type: application/json

{"images": ["/uploads/cert_abc123.png"]}
```

```json
{
  "success": true,
  "ocrText": "荣誉证书\n张三 同学...",
  "ocrFields": {
    "name": "蓝桥杯省赛一等奖",
    "level": "provincial",
    "category": "程序设计",
    "winner": "张三",
    "issuer": "中国软件行业协会",
    "date": "2025-04",
    "description": ""
  }
}
```

### 6.3 证书审核归档

```http
POST /api/admin/certificates/12/review
Authorization: Bearer <admin-token>
Content-Type: application/json

{"status": "verified", "reviewNote": "材料齐全，同意归档"}
```

响应中的 `award` 字段为自动生成的成果记录（`certificateId` 指向来源证书，幂等）。

### 6.4 智能体需求解析 → 落地

```http
POST /api/assistant/parse-requirement
Authorization: Bearer <member-token>

{"message": "做一个 AI 学习助手，能答疑和规划学习路径，10 月前上线"}
```

返回 `plan`（project + milestones + tasks，不写库）；确认后调用
`POST /api/assistant/apply-plan` 一次性创建并自动给负责人发通知。

### 6.5 CLI 等价调用

```bash
python -m cli auth login
python -m cli project list --status active --json
python -m cli award export --format csv --output awards.csv
```

证书识别/审核为 Web 可视化流程（成员证书管理页 + 管理端证书审核页）；
CLI 提供成果查询与导出（`award list` / `award export`），详见《CLI接口调用文档》。

## 七、错误码约定

| 错误码 | 说明 |
|--------|------|
| `bad_request` | 参数缺失/格式错误（400） |
| `validation_error` | 校验失败（400/422） |
| `auth_failed` | 账号或密码错误（401） |
| `account_disabled` | 成员账号停用（403） |
| `not_found` | 资源不存在（404） |
| `conflict` | 唯一约束冲突（409） |
| `not_configured` | OCR/AI/存储未配置（503） |
| `ocr_failed` / `ai_failed` | 外部服务暂不可用（502） |
| `storage_failed` | 文件存储失败（502） |

| 站点配置/页面/导入导出 | ❌ | ❌ | ✅ |
