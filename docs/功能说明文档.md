# 功能说明文档

> 项目：实验室综合官网及智能项目管理平台
> 更新日期：2026-08-09

## 一、六大板块总览

| 板块 | 入口 | 核心功能 |
|------|------|----------|
| 对外展示门户 | `/` 及公开子页 | 首页、关于、成员、项目、奖项、博客/公告、开源、研究方向、合作交流、时间线、入门、加入、联系我们 |
| 内部管理系统 | `/admin/*` | 成员、证书审核、项目（看板/里程碑/提醒/统计）、周报审阅、奖项、博客、页面、配置、申请、留言、数据 |
| 个人中心 | `/member/*` | 资料、我的项目/任务、资源中心、证书管理、通知、通讯录、AI 助手 |
| 证书智能识别 | 成员证书页 + 管理证书审核页 | AI 结构化识别、表单自动回填、人工修正、审核归档 |
| 智能项目管理智能体 | `/member/assistant` | 自然语言对话、需求拆解、任务规划、周报分析、定时提醒 |
| 双接口服务 | Web + `cli/` | Web 可视化 + CLI 命令行，共享数据库实时同步 |

## 二、功能清单

### 2.1 对外展示门户

- **首页**：Hero（视频背景）、简介、公告区、成员、项目、奖项、加入 CTA。
- **关于我们**：社团介绍、数据指标、活动照片墙。
- **团队成员**：按分组筛选、搜索、加载更多、成员详情弹窗。
- **研究方向** `/research`：技术领域、研究内容、应用场景（CMS 可维护）。
- **合作交流** `/cooperation`：校企合作、校际交流、学术活动、参会参展（CMS 可维护）。
- **成果展示**：项目画廊 + 项目详情；奖项列表 + 奖项详情。
- **博客/公告**：分类筛选、搜索、置顶排序、公告已读追踪（成员）。
- **招新/入驻**：招新信息页 + 三步报名表单（实时校验、限流）。
- **联系我们** `/contact`：地址/邮箱/电话/社交平台 + 留言表单（匿名可选，后台可回复）。

### 2.2 后台管理系统

- 权限：管理员 JWT 独立于成员体系，全部管理接口鉴权。
- 内容管理：成员/项目/奖项/博客/页面全 CRUD，站点配置在线编辑。
- 证书审核：图片与 AI 字段核对、通过自动归档成果库、驳回原因通知。
- 项目管理：项目详情 6 Tab（概览/看板/里程碑/周报/提醒/统计）。
- 周报审阅：列表筛选、详情、AI 分析、批注、人工完成度。
- 报名/留言：审核与回复处理。
- 数据：全站导出（JSON）、导入（replace/merge）。

### 2.3 个人中心

- 个人资料编辑、密码修改。
- 我的项目/任务/看板：任务 5 列状态流转。
- 资源中心：文件夹树、上传下载、搜索（登录可见）。
- 通知中心：未读计数、已读管理。
- 通讯录：成员联系方式。

### 2.4 证书智能识别（重点功能）

完整闭环：上传图片 → AI 结构化识别（获奖名称/等级/类别/获奖人/颁奖单位/获奖时间/描述 + 原文）
→ 表单自动回填 → 人工修正 → 提交 → 管理员审核 → 通过自动归档至实验室成果库 + 站内通知；
驳回后成员修改自动重新送审。

### 2.5 智能项目管理智能体

- 27 个工具：项目/任务/里程碑/成员/周报/提醒/通知/资源/获奖/证书/健康度查询。
- 对话持久化与会话隔离，SSE 流式输出，限流与长度防护。
- 需求拆解 → 方案确认 → 一键落地创建项目+里程碑+任务。
- 周报 AI 分析（评分/风险/建议/审核报告）。
- 定时提醒扫描：任务截止、周报催收、自定义提醒 → 站内通知。

### 2.6 双接口（Web + CLI）

- CLI 命令组：auth/status/project/task/report/award/member/config/reminder/notify。
- 输出：人类表格 或 `--json` 机器可读；错误退出码 1。
- 数据同步：CLI 与 Web 调用同一 REST API，实时一致。

## 四、主要配置项

| 配置 | 说明 |
|------|------|
| `FLASK_ENV` | development/production/testing |
| `DATABASE_URL` | 默认 SQLite，可切换 PostgreSQL/MySQL |
| `SECRET_KEY` / `JWT_SECRET_KEY` | 会话与 JWT 密钥（生产用 secret 文件） |
| `CORS_ORIGINS` | 允许的前端来源 |
| `AI_*` | 智能体/周报分析模型配置 |
| `OCR_*` | 证书识别视觉模型配置 |
| `OSS_*` | 阿里云 OSS 对象存储（可选） |
| `REMINDER_SCAN_ENABLED/INTERVAL` | 提醒扫描开关与间隔 |
