# 资源中心开发文档

> 当前状态：基础闭环已完成；版本历史、评论、分享、管理端审核、AI 搜索等高级能力已确认暂缓。

## 一、当前实现范围

资源中心当前面向登录成员开放，入口为 `/member/resources`。实现目标是满足内部资料的基础存放、浏览和下载，不再按早期 Vue 版高级知识库方案继续扩展。

### 已完成

- 成员端资源页面：`frontendnew/src/components/member/ResourceCenter.tsx`
- 成员端 API 封装：`frontendnew/src/services/memberApi.ts`
- 后端模型：
  - `ResourceFolder`
  - `ResourceFile`
- 后端接口：
  - `GET /api/member/resources/folders`
  - `POST /api/member/resources/folders`
  - `GET /api/member/resources/files`
  - `POST /api/member/resources/upload`
  - `PUT /api/member/resources/<id>`
  - `DELETE /api/member/resources/<id>`
- 上传存储：`StorageService`，本地存储默认可用，OSS 可选。
- 权限控制：所有资源接口需要成员 JWT。
- 文件软删除：删除文件时标记 `is_deleted=True`。

## 二、功能说明

### 2.1 文件夹

- 支持根目录和子文件夹。
- 支持在当前目录新建文件夹。
- 支持逐级进入文件夹和返回上级。
- 当前面包屑为轻量实现，依赖前端当前导航栈，不做完整 ancestor 链查询。

### 2.2 文件

- 支持上传到当前文件夹或根目录。
- 支持按文件名搜索。
- 支持下载已上传文件。
- 支持成员端软删除文件。
- 文件大小受 `MAX_CONTENT_LENGTH` 限制。

### 2.3 允许格式

当前成员端允许格式定义在 `backend/routes/member.py` 的 `ALLOWED_EXTENSIONS`。安全加固后，`svg`、`html`、`js` 等浏览器可执行风险较高的格式不再允许作为资源上传：

```python
{
    'png', 'jpg', 'jpeg', 'gif', 'webp',
    'pdf', 'mp4', 'webm', 'zip', 'rar',
    'doc', 'docx', 'xls', 'xlsx', 'ppt', 'pptx',
    'txt', 'md', 'json', 'xml', 'csv',
    'py', 'ts', 'css', 'java', 'go', 'rs',
}
```

上传时还会读取文件头进行内容校验，拦截扩展名与内容不匹配的伪装文件。

## 五、后续恢复开发时建议

如后续重新启用高级资源中心，建议按以下顺序单独排期：

1. 管理端资源恢复/永久删除和基础审计。
2. 上传内容安全校验与预览安全沙箱。
3. 标签、下载次数、评论。
4. 版本历史。
5. 分享链接。
6. AI 搜索与标签推荐。
